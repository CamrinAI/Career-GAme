# Initial IAM release completion plan

Finish the original five-sprint browser release. Existing lessons, Warden combat, earned progression, contracts and GitHub Pages delivery remain the foundation. Do not add the explicitly deferred guild, multiplayer, 3D hub or additional career classes.

Remaining release work:
1. Career Pathfinder: an accessible entry flow for the Cloud Warden campaign, experience selection, career awakening and accurate certification/project guidance; existing players can revisit it without resetting progress.
2. Persistent learning review: save question attempts, correct/incorrect answers and review needs; offer targeted practice with explanations. Existing saves migrate without fabricated learning history.
3. Portable saves: downloadable backups, validated import with a review/replace step, and unchanged explicit reset protection.
4. Combat presentation: original Hunter artwork, distinct attack/defend/special/ultimate/counterattack feedback and phase changes, respecting reduced motion and sound settings.
5. Final polish: readable lesson/control text, route focus and mobile layouts; tests for learning records, backup validation, saves, rewards and battle rules.
6. Production build, browser verification, GitHub checks, public deployment, final release notes and a prioritized suggestion table.

Definition of release complete: new players can awaken a character, learn, review mistakes, fight and win/lose, earn progression, back up their progress and play on the published preview. Future campaign chapters stay labeled as planned. No auto-merge of the review PR.
